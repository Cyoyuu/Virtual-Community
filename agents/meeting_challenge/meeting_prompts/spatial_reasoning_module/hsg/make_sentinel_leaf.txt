# ================================================
# Prompt: Make a Sentinel Leaf Node Using Ego View
# ================================================

# Purpose:
# Given ego-view sensory data or description, construct a leaf node representing
# a sentinel in the hierarchical scene graph. The node should encode key properties
# such as location, posture, motion, and detection risk.

# ------------------------------------------------
# Input Variables:
#   $EgoDescription   → Textual or visual description of what the agent perceives.
#   $AgentPose        → Agent’s own (x, y, orientation) or a qualitative pose (e.g., “facing north”, “at corner of alley”).
#   $TimeStamp        → Simulation time, used for temporal grounding.
#   $ConfidencePrior  → (Optional) estimated confidence from perception module (float 0–1).
#   $ParentNodeHint   → (Optional) name of nearby area/building/road node this sentinel likely belongs to.

# ------------------------------------------------
# Output Requirements:
# Return a **single JSON object** describing the sentinel leaf node, following this schema:

{
  "node_id": "string (unique identifier, e.g., sentinel_leaf_XXXX)",
  "name": "Sentinel_X",
  "type": "sentinel",
  "connectivity_center": {"x": float, "y": float},
  "properties": {
    "pose_relative_to_agent": "string (e.g., '10 meters ahead to the left')",
    "motion_state": "string (e.g., 'stationary', 'patrolling', 'turning')",
    "detection_risk": float (0–1),
    "confidence": float (0–1),
    "source": "ego_view",
    "description": "concise textual summary of appearance and behavior",
    "last_seen": "timestamp"
  },
  "parent_hint": "string or null (optional reference to parent node name)",
  "children": []
}

# ------------------------------------------------
# Instructions for the Model:

1. **Extract Sentinel Information.**
   - From the ego-view text, identify if there’s one or more sentinels visible.
   - If multiple, create **only one leaf node** describing the most relevant or central one.

2. **Infer Motion and Risk.**
   - If described as moving or scanning, set `"motion_state": "patrolling"` and higher `"detection_risk"`.
   - If standing idle, use `"stationary"` and moderate risk.
   - Risk values: 0.2 (low) to 0.9 (high).

3. **Estimate Relative Location.**
   - Use spatial expressions like “ahead”, “to the right”, “behind”, and approximate distances (meters if mentioned or inferred).
   - Convert to `"pose_relative_to_agent"` as text.
   - Assign a plausible `(x, y)` offset relative to the agent’s coordinate frame (0,0 = ego center).

4. **Compose Description.**
   - Combine color, shape, behavior cues.
   - Mention whether the sentinel is aware of or facing the agent.

5. **Finalize JSON Output.**
   - Must be valid JSON only, matching schema.
   - Fill in timestamp and parent hint if available.
   - Use confidence from `$ConfidencePrior` if provided; otherwise estimate.

# ------------------------------------------------
# Example Input:

$EgoDescription:
"""
You see a tall metal sentinel about 15 meters ahead, slowly rotating its upper body as if scanning.
Its red sensor light occasionally sweeps across the path in front of you.
"""

$AgentPose:
"At intersection corner, facing north."

$TimeStamp:
"2025-11-02T18:45:00Z"

$ConfidencePrior:
0.92

$ParentNodeHint:
"Main Road"

# ------------------------------------------------
# Example Output:

{
  "node_id": "sentinel_leaf_1845A",
  "name": "Sentinel_1",
  "type": "sentinel",
  "connectivity_center": {"x": 0, "y": 15},
  "properties": {
    "pose_relative_to_agent": "15 meters ahead",
    "motion_state": "patrolling",
    "detection_risk": 0.85,
    "confidence": 0.92,
    "source": "ego_view",
    "description": "Tall metallic sentinel scanning the area with a red sensor light.",
    "last_seen": "2025-11-02T18:45:00Z"
  },
  "parent_hint": "Main Road",
  "children": []
}
