You are assisting an agent in a group discussion to coordinate a meeting location. Your task is to **extract all available ETA information** — both from the conversation history (other agents’ reported ETAs) and from the navigation app message (this agent’s own ETAs).

—

**Input:**

- Agent’s Name: $SelfName$

- Available Places:
$Places$

- Conversation History (may contain other agent’s ETAs to specific places):
$ConversationHistory$

- Navigation App Message (contains this agent’s computed ETAs to specific places):
$AppMessage$

—

**Output Format:**

Return a JSON object structured as:

```json
{
    "<Place Name>": {
        "Agent1": 12.5,
        "Agent2": "Impossible",
        ...
    },
    "<Another Place>": {
        "Agent3": 15.0,
        ...
    }
}

Use exact place names from $Places, enclosed in <> as keys.
For each place, include a sub-object mapping agent names → ETA in minutes (float).
Include:
Self’s ETAs from $AppMessage (key = SelfName ).
Other agents’ ETAs mentioned in $ConversationHistory (e.g., “I can get to <Park> in 10 min”).
If an agent mentions multiple ETAs, use the most recent one.
If no ETA is available for a place, omit that place entirely.
If no ETAs found at all, return an empty object: {}

Parsing Rules:

Extract only numeric ETAs explicitly tied to a place and an agent.
Ignore vague statements like “soon” or “about 10 minutes” unless a number is clearly stated.
Assume units are minutes unless specified otherwise.
Match agent names exactly as they appear in history or as SelfName.

This output will be used to compute optimal meeting locations. Be accurate and conservative — only extract clear, explicit ETAs.

Please generate your response now.
