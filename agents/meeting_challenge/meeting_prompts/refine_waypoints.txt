You have just encountered active sentinels on your route. The original path may no longer be safe. Your task is to generate a new sequence of waypoints that safely lead to the destination while avoiding dangerous zones whenever possible.

---

### Input

**Map Legend:**
- '.': Open space — safe to move through.
- 'X': Obstacle — impassable area.
- 'A': Your current position.
- 'D': Dangerous zone — active sentinel presence. Avoid these cells unless no alternative path exists.
- 'T': Target destination.
- 'R': Reference route — the original path that has become unsafe.

**Map Description:**
- The map is represented as a grid.
- Each cell corresponds to a 10m × 10m area.
- Coordinates are defined as (y, x) with (0, 0) at the top-left corner.

**Map:**
$Map$

---

### Task

Generate a **new safe route** from 'A' to 'T':
1. Use 'P' to mark your newly planned path on the grid.
2. The route should reach 'T'.  
   - If 'T' is completely blocked by obstacles, end the route as close as possible.
3. The path should **avoid 'D' cells** unless absolutely necessary.
4. Ensure the map dimensions remain identical to the input map.

---

### Output Format

1. First, output the **updated map**, maintaining the same structure as the input, but with 'P' marking the new route.
2. Immediately after, output a **JSON object** listing the route’s waypoints (each in `[x, y]` format).

No explanations or comments — only the map and the JSON object.

**Example:**

...PP..
..PXT..
A.PD...

```json
[
    [10.0, 10.0],
    [25.0, 15.0],
    ...
]
```
Now generate your output.
