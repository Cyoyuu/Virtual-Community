$TaskDescription$

Now the agent is in a group discussion. The goal is to select — from the provided list — the location that minimizes the travel time of the LAST agent to arrive. 

Previous analysis shows that **full agreement has NOT been reached**. Now, your task is to help the agent decide its next move in the discussion: Should it **speak**, **query for more information**, or **wait**? $Stalling$

---

**Input:**

Current Time:
$CurrentTime$

- Agent’s Name: $SelfName$

- Agent's position: $SelfPose$

- Current Agent Opinions:
$AgentOpinions$

- Available Places: 
$Places$

- Conversation History: 
$ConversationHistory$

- Extracted agent positions (contains other agents' locations extracted from previous conversation):
$KnownPoses$

- Known ETAs (contains agents' computed ETAs to specific places known by this agent in "HH:MM:SS" format or "Impossible"):
$KnownETA$

- Missing informations you have analyzed.
$MissingInfo$

Note that the team only share the conversation history, instead of all infos.

---

**Output Format:**

Return a JSON object with two fields:

```json
{
    "action": "speak|query|wait",
    "explanation": "brief explanation (under 80 words)"
}
```

---

Guidelines for Choosing Action:

You must choose from three types of actions: "speak" with teammates, "query" the navigation app, or just "wait".

“speak” — if:

The agent has enough info to propose, support, or compromise.
Discussion is stalling or repeating. You want to finalize the discussion.
There’s a clear optimal or majority-preferred location to endorse.
You need information about other agents.
Someone is asking for your information and you already have that information.
No one respond you or speak anything during the last 5s, in which case you should say again.
In short, if you need to speak something, choose 'speak'. If so, set the 'explanation' to your speech intent. The intent should at least include one of the following three fields:
1. What you think about the destination. You want to propose a new destination, or support a good option already onthe table, or make a compromise between disagreement?
2. What questions are you answering? What information you want to provide?
3. What information are you asking for?

“query” — if:

The agent lacks its own ETA to one or more leading locations, so it will query the navigation app for this.
Someone is asking for your information and you don't have that information.
Some unknown places are mentioned, so you need to query the navigation app for this.
You want more information about a specific area.
In short, if you need to query the navigation app for something, choose 'query'. If so, set the 'explanation' to what you want to query about.

“wait” — if:

Other agents are actively speaking or querying.
The agent has nothing new to add yet.
Recent messages suggest convergence is imminent.

For example, if you need someone's ETA but haven't ask for it, go for "speak". If someone else have asked for that ETA, then "wait".

Be decisive and efficient. Prioritize progress over perfection. Prioritize answering questions over throwing questions. Avoid redundant proposals. If more than 25 seconds have passed without convergence, lean toward “speak” to drive consensus.
