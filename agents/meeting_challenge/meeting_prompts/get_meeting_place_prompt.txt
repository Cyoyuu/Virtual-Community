You are helping an agent in a city tasked with coordinating a meeting location with other agents. Your goal is to select — from the provided list — the location that minimizes the travel time of the LAST agent to arrive.

The agent you are helping is in a group discussion. This discussion is triggered by $Trigger$. Based on the info below, generate your next response. Be collaborative, decisive, and efficient — prioritize convergence over perfection. Avoid endless debate.

Informations:

Agent's Name:
$SelfName$

Agent position list:
$AgentPoses$

Place list:
$Places$

Conversation History so far:
$ConversationHistory$

Past Events:
$PastEvents$

Navigation app message:
$AppMessage$

The agent’s action should be returned in the following JSON format:
```json
{
    "type": "speak|wait|query|decide",
    "speech": "your message here"
}
```
So that your response can be directly parsed by json.

Guidelines for choosing the response:

type options:
"wait" → if you need more input before acting or waiting for others to speak. Then the agent will wait for the next turn.
"speak" → to propose, support, question, or compromise. Required before deciding. In this case, set "speech" to your speech content. Then the agent will speak to others.
"query" → you can query a navigation app for your estimated arrival time to that place, if needed. In this case, set "speech" to that exact place name. Then the agent will query the app and get a response.
"decide" → only if you’re confident ALL agents agree on one place. In this case, set "speech" to that exact place name. Then the agent will end discussion and start navigation.

Before speaking:
Try get necessary travel times from agent positions to places, by either querying the navigation app or simply catching information from others' speech.
Propose the most optimal location, or support/comment on existing suggestions.
If discussion is dragging, compromise — accept the most agreed-upon option.
Important constraints:
Mention places as <Place Name> — exact match required.
Keep speech under 100 words, 1–3 sentences. Be clear, polite, and action-oriented.
Never endlessly propose new locations. If 2+ rounds have passed without convergence, actively support or finalize the leading candidate.
Speak at least once before using "decide" — ensure others know you’re about to finalize.

Finally, return only a valid JSON object in the format shown above.
